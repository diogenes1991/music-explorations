# data/interim/ — extracted / re-organized, not yet model-ready

Examples: URMP viola stems extracted from the ensemble download, files
converted to a common sample rate, recordings split by piece/player for
later splitting. Everything here is derived from `data/raw/` by a script —
never hand-edit audio here, and never copy raw downloads here by hand.
Scripts that produce interim data should be in `scripts/` and named in
`DATASETS.md` when they are used.
